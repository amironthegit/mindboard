# افزونه‌ی MindBoard (مایندمپ و دیاگرام کروشه‌ای راست‌به‌چپ در Obsidian)

افزونه‌ی **MindBoard** ابزاری سبک، سریع و منعطف برای ترسیم نقشه‌های ذهنی (Mindmap) و درخت‌های معکوس استدلالی/کروشه‌ای (Bracket / Logic Trees) با پشتیبانی بومی از زبان‌های راست‌به‌چپ (فارسی و عربی) در محیط ابسیدین است.

این افزونه بدون نیاز به کتابخانه‌های سنگین، دیاگرام‌ها را با کدهای برداری SVG رسم کرده و امکان تنظیمات لحظه‌ای، شخصی‌سازی بصری و خروجی باکیفیت تصویری را در اختیارتان می‌گذارد.

> ⚠️ **نکته برای مشاهده‌ی صحیح نمودارها:**
>
> نمونه کدهای آورده شده در این مستند، با استفاده از موتور پردازشگر اختصاصی این افزونه رندر می‌شوند. برای مشاهده‌ی نمودارهای گرافیکی، کادرها و خطوط اتصال، باید این افزونه در ابسیدین شما نصب و فعال باشد.

## ویژگی‌های کلیدی

* **پشتیبانی کامل از زبان‌های RTL و LTR:** طراحی پایه منطبق بر جهت راست‌به‌چپ بدون به‌هم‌ریختگی تورفتگی‌ها.
* **دو حالت دیاگرام مجزا:**
  1. `mindmap`: مایندمپ درختی افقی یا عمودی استاندارد.
  2. `bracket`: نمودار درختی معکوس و مقدمه‌چینی با آکولاد و کروشه جهت نمایش استدلال‌ها و نتیجه‌گیری‌ها.
* **تغییر مشخصات اختصاصی هر بلوک بدون باز کردن تنظیمات:** دکمه‌های نوار ابزار بالای نمودار برای تغییر شکل، خط، تراز متن و رنگ دیاگرام همان بلاک.
* **پیش‌نمایش لایو (Live Preview) برای اسلایدرهای عرض:** امکان تنظیم حداکثر عرض عنوان اصلی و سایر گره‌ها به‌صورت آنی با حرکت اسلایدر.
* **پشتیبانی از قالب‌بندی مارک‌داون:** استفاده از بولد، ایتالیک، لینک‌ها و حتی شکست دستی سطر با `<br>`.
* **ابزار خروجی پرقدرت:** دانلود مستقیم نمودار با کیفیت برداری `SVG` یا تصاویر `PNG` و `JPG`.

## نحوه‌ی نصب و راه‌اندازی

1. پوشه‌ای با نام `mindboard` در مسیر پلاگین‌های والت خود بسازید: `YourVault/.obsidian/plugins/mindboard/`
2. سه فایل افزونه را داخل این پوشه قرار دهید:
   * `main.js`
   * `styles.css`
   * `manifest.json`
3. در تنظیمات ابسیدین به بخش **Community plugins** رفته، فهرست را ریفرش کنید و **MindBoard** را فعال نمایید.

## ساختار و نشانه‌گذاری‌ها (Syntax)

دیاگرام‌ها با استفاده از بلاک کد (Code Block) با زبان `mindmap` یا `bracket` ساخته می‌شوند.

### ۱. نشانه‌های مایندمپ (`mindmap`)

* **ساختار سلسله‌مراتبی:** با کلید `Tab` یا فاصله‌ها مشخص می‌شود.
* **عنوان با فلش (`##`):** متن بین دو نشانه‌ی `##` با یک فلش به کادر قبلی متصل می‌شود.
* **توضیحات کمرنگ (`::`):** متن بین دو نشانه‌ی `::` با فونت کوچک‌تر و رنگ ملایم‌تر زیر گره قرار می‌گیرد.
* **آکولاد گروهی (`@@`):** با قرار دادن `@@نتیجه` در انتهای یک یا چند گره مجاور، آکولاد خلاصه‌سازی دور آن‌ها رسم می‌شود.

### ۲. نشانه‌های بلاک کروشه (`bracket`)

* هرچه تورفتگی (سطح تب) بیشتر باشد، آن عبارت «نتیجه» یا گام بعدیِ ردیف‌های با تورفتگی کمتر قبلی است.

## تنظیمات درون‌بلاک (Inline Directives)

شما می‌توانید مشخصات هر دیاگرام را مستقیماً در خطوط ابتدایی آن بلاک با علامت `@` تعیین کنید. این مقادیر بر تنظیمات کلی افزونه اولویت دارند:

| دستور درون بلاک | گزینه‌ها / مقادیر معتبر | توضیح |
| :--- | :--- | :--- |
| `@shape=` | `rounded`, `rect`, `pill`, `circle`, `diamond`, `none` | شکل هندسی کادرهای دیاگرام |
| `@line=` | `curve`, `straight`, `elbow` | استایل خطوط اتصال (منحنی، مستقیم، زانویی) |
| `@color=` | `branch`, `level`, `sibling` | حالت رنگ‌آمیزی شاخه‌ها یا سطوح |
| `@bracket=` | `curly`, `square`, `line` | شکل آکولادها (منحنی، کروشه مستطیلی، خط مستقیم) |
| `@arrow=` | `thin`, `equal`, `implies`, `bar`, `sleek`, `dart`, `bold` | استایل فلش‌های هدایت‌کننده |
| `@dir=` | `rtl`, `ltr`, `ttb`, `btt` | جهت ترسیم (راست‌به‌چپ، چپ‌به‌راست، بالا‌به‌پایین، پایین‌به‌بالا) |
| `@align=` | `center`, `right`, `left`, `justify` | تراز متن داخل جعبه‌ها |
| `@rootwidth=` | عدد بر حسب `em` (مثلاً `20`) | حداکثر عرض مجاز برای گره ریشه (اصلی) |
| `@nodewidth=` | عدد بر حسب `em` (مثلاً `35`) | حداکثر عرض مجاز برای سایر گره‌ها |
| `@blockwidth=` | عدد بر حسب `em` (مثلاً `30`) | حداکثر عرض جعبه‌ها در بلاک کروشه |
| `@leader=` | `on`, `off` | فعال/غیرفعال کردن خط‌چین راهنما در بلاک کروشه |

## نوار ابزار روی هر نمودار

با بردن نشانگر ماوس روی گوشه بالایی هر نمودار، نوار ابزاری هوشمند ظاهر می‌شود:

1. **دانلود نمودار:** ذخیره با فرمت‌های `SVG`، `PNG` یا `JPG` در والت.
2. **نمایش/مخفی‌سازی توضیحات (`::`):** سوییچ سریع نمایش یا پنهان کردن یادداشت‌های زیر گره‌ها.
3. **دکمه‌های تنظیمات اختصاصی:** تغییر شکل، نوع خطوط، پالت رنگ، جهت، کروشه، فلش و تراز متن برای همان نمودار.
4. **دکمه‌ی تنظیم اندازه (اسلایدر زنده):** تغییر حداکثر عرض عنوان اصلی و گره‌ها با مشاهده‌ی زنده و لحظه‌ای ابعاد.

## کلیدهای میانبر و دستورات پالت

در حین تایپ داخل بلوک‌های `mindmap` و `bracket`:

* **`Enter`:** حفظ هوشمند تورفتگی سطر قبلی.
* **`Tab` و `Shift+Tab`:** افزایش و کاهش آسان سطح گره‌های انتخاب‌شده.

از بخش Command Palette (`Ctrl/Cmd + P`) نیز می‌توانید با دستورات زیر شکل‌ها و رنگ‌ها را به‌صورت چرخشی تغییر دهید:

* `RTL Mindmap: Cycle node shapes`
* `RTL Mindmap: Cycle line styles`
* `RTL Mindmap: Cycle color modes`
* `RTL Mindmap: Toggle direction (RTL/LTR)`

## نمونه‌های کاربردی و الگوها

کدهای زیر را می‌توانید مستقیماً کپی کرده و داخل یادداشت‌های خود قرار دهید:

### نمونه ۱: نقشه‌ی ذهنی استاندارد همراه با عنوان، توضیح و آکولاد گروهی

```mindmap
@shape=rounded
@line=curve
@color=branch
مدیریت پروژه
	فاز اول: برنامه‌ریزی##تعیین اهداف##
		تحلیل نیازمندی‌ها::بررسی دقیق با ذینفعان::
		زمان‌بندی و بودجه@@آماده برای شروع@@
	فاز دوم: اجرا
		طراحی معماری
		پیاده‌سازی کدها
	فاز سوم: کنترل کیفیت
		تست‌های خودکار
		بررسی امنیتی
```

### نمونه ۲: استدلال منطقی و استنتاج چندمرحله‌ای (`bracket`)

```bracket
@bracket=curly
@shape=pill
@align=center
شواهد و فرضیات اولیه
مستندات تاریخی معتبر
	بررسی صحت ادعا
تحلیل آماری جامعه نمونه
	اثبات فرضیه اول
		نتیجه‌گیری نهایی تحقیق##گزارش رسمی##
```

### نمونه ۳: دیاگرام سازمانی بالا‌به‌پایین (`ttb`)

```mindmap
@dir=ttb
@shape=pill
@line=elbow
مدیرعامل
	معاونت فنی
		تیم بک‌اند
		تیم فرانت‌اند
	معاونت مالی
		حسابداری
		منابع انسانی
```

### نمونه ۴: شکست دستی خطوط بدون تغییر ساختار درخت

اگر تمایل دارید متنی طولانی بدون چند قسمتی شدن، در دو خط مجزا قرار بگیرد، کافی است از تگ `<br>` استفاده کنید:

```mindmap
مفهوم بنیادین
	تعریف اول که طولانی است<br>و در دو خط خوانده می‌شود
	تعریف دوم
```

## شخصی‌سازی پیشرفته با CSS

برای شخصی‌سازی رنگ‌ها و فاصله‌ها، می‌توانید یک قطعه کد CSS (CSS Snippet) در بخش تنظیمات ظاهر ابسیدین فعال کنید:

```css
.mm-container {
  /* تنظیم پالت رنگ شاخه‌ها */
  --mm-c0: #2f80ed;
  --mm-c1: #27ae60;
  --mm-c2: #f2994a;
  --mm-c3: #9b51e0;

  /* تنظیم فاصله‌ها */
  --mm-gap-x: 3.5em; /* فاصله بین سطوح */
  --mm-gap-y: 0.8em; /* فاصله گره‌های هم‌سطح */
}
```
